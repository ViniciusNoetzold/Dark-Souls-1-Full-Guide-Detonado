# Pasta de Imagens das Conquistas (Steam Achievements)

Coloque aqui os arquivos de imagem das conquistas.

### Formatos e Nomes aceitos:
Você pode nomear os arquivos de acordo com o `apiname` ou ID da conquista em minúsculas ou maiúsculas:
- Exemplo: `ACHIEVEMENT_THE_DARK_SOUL.png` ou `the_dark_soul.png` / `the_dark_soul.jpg`
- Exemplo: `ACHIEVEMENT_BOND_OF_A_PYROMANCER.png` ou `bond_of_a_pyromancer.png`
- Ou você pode enviar as imagens diretamente no chat e o assistente as integrará automaticamente!
