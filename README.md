# Guia Dark Souls 1 (Prepare to Die Edition)

Este repositório contém o guia 100% completo e passo a passo (Road Guide) para Dark Souls 1 (Prepare to Die Edition), acompanhado de materiais extras detalhados.

## Estrutura do Projeto

*   **Raiz (`/`)**: Contém os arquivos do **Road Guide**. Estes são os guias principais, feitos para serem seguidos passo a passo durante a gameplay. Eles te guiam por cada área, mostrando onde ir, o que pegar, e estratégias para chefes.
*   **`Episódios Detalhados/`**: Contém versões aprofundadas dos episódios, com informações extensas sobre a lore, NPCs encontrados, itens obtidos e evolução detalhada da build do personagem.
*   **`Maps/`**: Contém mapas visuais das áreas do jogo para auxiliar na navegação.

## Como Usar

Comece pelo `Episódio 01 - Rota Inicial e Asylum.md` na raiz do projeto e siga a numeração. A primeira seção de cada guia sempre detalha a "Evolução da Build" do personagem para que você possa acompanhar o progresso dos atributos e equipamentos.
