## 🎯 Build Reference — Evil Gilberton (Pyro/Dex)

### Stats Iniciais (Pyromancer)
| Stat | Valor Base | Notas |
|------|------------|-------|
| Vitality | 12 | HP |
| Attunement | 12 | 1 slot (Fireball) |
| Endurance | 11 | Stamina/Equip Load |
| Strength | 12 | Req. armas |
| **Dexterity** | **10 → 24** | **Upado Ep.01 para Rapier, Ep.06 para 24** |
| Resistance | 10 | |
| Intelligence | 10 | |
| Faith | 8 | |

### Progressão Planejada (Baseada no Vídeo)
- **Dex:** 12 → 14 → 16... → **24 (Ep.06)** → 40-45 (soft cap)
- **Attunement:** 12 → **14 (Ep.07 - 3 slots)** → **16 (Ep.07 - 4 slots)** → **19 (Ep.07 - 5 slots)** → 23 (6 slots)
- **Vitality/Endurance:** Conforme necessidade de survivability e equip load
- **Intelligence:** Só se for usar sorceries (não é o foco)

### Pyromancies Aquisição (Ordem)
1. ✅ **Fireball** (inicial)
2. ✅ **Combustion** (Ep.06 - comprada Laurentius pós-resgate)
3. ✅ **Power Within** (Corpo pego Ep.06 Blighttown - Att 14+)
4. ✅ **Great Fireball** (Ep.07 - Quelana 100 almas)
5. ✅ **Great Combustion** (Ep.07 - Quelana 5k almas)
6. ✅ **Great Chaos Fireball** (Ep.08 - Quelana/Laurentius? + Bellowing Ring)
7. 🔜 **Fire Orb** / **Fire Tempest** / **Chaos Storm** (Quelana - Chaos +30)
8. 🔜 **Iron Flesh** (Laurentius compra)
9. 🔜 **Flash Sweat** (Laurentius compra - útil Quelaag!)
